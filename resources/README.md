# Source index

The sources this research draws on. Mostly AWS Business Strategist learning-path material, plus the two ISO
standards. Each source gets a fuller synthesis note in `research/sources/` as it's processed. This page is
just the list.

**Copyright.** Third-party material is linked, not republished. Local copies (PDFs) stay out of git (see
`.gitignore`). AWS material is free to read, but free to read isn't the same as licensed to redistribute.
ISO/IEC standards are paid, copyrighted texts: this repo cites clause numbers and titles and paraphrases
their intent, and never quotes or commits them.

Access dates are the date the local copy was saved or the link was captured.
